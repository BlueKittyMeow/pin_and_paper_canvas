## Planned Features

- Bounded canvas with configurable limits
- Pan gesture (two-finger drag)
- Zoom gesture (pinch)
- Entity drag-to-move
- Two-finger rotation
- Z-ordering / layering
- Selection state
- Viewport culling (render only visible)
